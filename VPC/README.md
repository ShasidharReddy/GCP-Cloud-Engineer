# VPC

Collection of VPC helper scripts and gcloud snippets.

Key files:
- vpc.sh — create basic VPC and subnet
- nat.sh — Cloud NAT setup
- vpcPeering.sh — VPC peering examples
- firewall.sh — sample firewall rules
- sharedvpc.sh — Shared VPC helper
- gcloudCommands.sh — assorted useful commands

Usage:
Make scripts executable (chmod +x) and run with an authenticated gcloud account. See V2/4-VPC for detailed guides.
