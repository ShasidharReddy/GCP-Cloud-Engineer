# Shasi Google Cloud Platform

Collection of Google Cloud Platform examples, scripts and how-to guides.

Key locations:
- V2/: Primary, updated guides and working examples (preferred).
- GCS.md, cloud_spanner.md, database_migration.md, vpn_dynamic_ha.md: focused HOWTOs.
- gcloud_commands.sh: useful command snippets for common tasks.

Quick start:
1. Clone the repo.
2. Review V2/ for the latest step-by-step guides.
3. Run scripts in a safe environment and adapt to your project.

Contributing: send PRs, open issues for missing/corrected content.
